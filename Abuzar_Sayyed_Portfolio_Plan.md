## 2. Theme & Design Direction

### Overall Vibe
- **Dark Mode First** → Modern developer aesthetic (near-black / deep navy background)
- **Soft Gradients + Glow** → Purple / blue / cyan accents for a premium “vibe coding” feel
- **Clean & Minimal** → No clutter, clear hierarchy, generous spacing
- **Smooth Animations** → Subtle entrance and hover effects using Framer Motion
- **Mobile First** → Fully responsive on phone, tablet, and desktop

### Color Palette
| Role              | Color        | Hex                   |
|-------------------|--------------|-----------------------|
| Background        | Near Black   | `#0a0a0f` / `#111827` |
| Primary Accent    | Soft Purple  | `#8b5cf6`             |
| Secondary Accent  | Cyan         | `#06b6d4`             |
| Text Primary      | White        | `#f8fafc`             |
| Text Muted        | Gray         | `#94a3b8`             |
| CTA / Highlight   | Coral/Pink   | `#e94560`             |

### Typography
- **Headings** → Inter or Geist (bold, modern sans-serif)
- **Body** → Inter / system-ui (clean and readable)

## 5. Development Plan (Step by Step)

1. **Setup** → Create Next.js project with `create-next-app`, install Tailwind CSS and Framer Motion
2. **Layout & Theme** → Set up dark theme, colors, fonts, and global styles
3. **Components** → Build Navbar, Hero, About, Services, Projects, Contact, and Footer as separate components
4. **Content Fill** → Add real bio, services, and projects (you will provide the details)
5. **Animations & Polish** → Add smooth scroll, hover effects, and loading states
6. **Responsive Check** → Test on mobile, tablet, and desktop
7. **Deploy** → Deploy on Vercel and push the code to GitHub
