# Abuzar Sayyed – Portfolio

**Vibe Code Developer | Landing Pages & Web Solutions**

Modern, dark-themed portfolio built with **Next.js 15**, **Tailwind CSS**, **TypeScript**, and **Framer Motion**.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React (icons)

## Project Structure

```
src/
├── app/
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
└── components/
    ├── Navbar.tsx
    ├── Hero.tsx
    ├── About.tsx
    ├── Services.tsx
    ├── Projects.tsx
    ├── Skills.tsx
    ├── Contact.tsx
    └── Footer.tsx
```

## Customization

- Update bio in `About.tsx`
- Replace placeholder projects in `Projects.tsx`
- Add real contact details in `Contact.tsx`
- Adjust colors in `tailwind.config.ts` and `globals.css`

## Deploy

Recommended: Deploy on [Vercel](https://vercel.com) for best Next.js support.
